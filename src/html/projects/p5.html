Description

Ce projet a été réalisé en collaboration avec Thales dans le cadre de la SAÉ15. L’objectif était de concevoir un système complet et sécurisé permettant la capture d’images de bancs de test et leur consultation via une application web.

Le système repose sur un microcontrôleur Pico et un Raspberry Pi pour la prise de photos, ainsi qu’une application web assurant le stockage, l’affichage et la gestion sécurisée des données.

Fonctionnalités principales

• Gestion hiérarchisée des comptes (utilisateur, modérateur, administrateur)
• Système d’authentification et de contrôle des accès
• Capture d’images à distance via Raspberry Pi
• Galerie web dynamique et sécurisée
• Base de données pour utilisateurs, images et journaux d’activité

Compétences développées

• Développement web full-stack
• Programmation embarquée (Pico / Raspberry Pi)
• Gestion des droits et sécurité applicative
• Conception de bases de données
• Travail en mode projet avec un partenaire industriel
