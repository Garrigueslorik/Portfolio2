Projet Thales – Phase de développement

SAÉ15 · 1ère année · Projet industriel (Thales) · Difficulté : ★★★☆

Description

Cette phase correspond au développement complet du système fonctionnel du projet mené avec Thales. L’objectif était de permettre la prise de photos à distance via un Raspberry Pi et un Pico, puis leur affichage sécurisé sur une application web dynamique.

J’ai travaillé sur l’ensemble de la chaîne : du code embarqué jusqu’au back-end web, avec une attention particulière portée à la sécurité, la gestion des rôles et des sessions.

Architecture & technologies

• PHP / HTML / CSS (application web)
• MySQL (base de données relationnelle)
• Python (scripts embarqués)
• Raspberry Pi & Pico
• Architecture client–serveur

Fonctionnalités clés

• Authentification sécurisée avec gestion des rôles
• Base de données utilisateurs, images et logs
• Capture d’images pilotée à distance
• Galerie web dynamique
• Journalisation des actions consultable par les rôles autorisés

Compétences développées

• Développement back-end et bases de données
• Programmation embarquée
• Sécurité applicative (sessions, droits, logs)
• Conception d’architecture logicielle
• Travail en conditions industrielles
